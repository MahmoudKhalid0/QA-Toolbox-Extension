🧪 QA-Toolbox — Console Test Page

Some logs/warnings/errors fire automatically on load. Use the buttons to fire more after load, then open QA-Toolbox → Debug to see them and try Explain & Fix.

The spam button fires 2000 logs at once — the old tool would freeze; this one shouldn't.

🌐 Network requests

Fire fetch/XHR requests, then open QA-Toolbox → Debug → Network. Failed ones (4xx/5xx/errors) get a badge and can be analyzed with Explain & Fix.
